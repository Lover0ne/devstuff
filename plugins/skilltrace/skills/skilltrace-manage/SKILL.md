# Skilltrace Skill Management

## Overview

Manage skills auto-generated by Skilltrace. List, search, inspect, and replay.

## Commands

### List all skills
```bash
bash "${CLAUDE_PLUGIN_ROOT}/hooks/wrapper.sh" skills
```
Returns JSON with all skills grouped by project, including names, descriptions, versions, and dates.
Users can also run `/skilltrace-skills` for a formatted view.

### Search by keyword
Parse skills output and filter by name, tags, or description matching the user's query.

### Inspect a skill
Read the SKILL.md file at `.claude/skills/{skill-id}/SKILL.md` in the current project.

### Remove a skill
Delete the `.claude/skills/{skill-id}/` directory in the project, then remove from registry:
```bash
bash "${CLAUDE_PLUGIN_ROOT}/hooks/wrapper.sh" registry --remove {skill-id}
```

### Replay a skill
Read the SKILL.md and follow its steps in the current project context.
